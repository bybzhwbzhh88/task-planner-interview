## 复跑

在本目录按 [README](README.md) 启动服务并安装测试依赖后，另开终端运行：

```sh
npm run check
npm run verify
npm run verify:theme
```

本次复用了已安装的 Playwright，执行等价命令 `node verify.mjs`，通过 `PLAYWRIGHT_MODULE_PATH` 指向现有模块。常规安装无需设置该变量。可选 `BASE_URL` 用于检查其他本地端口，默认 `http://127.0.0.1:4310`。

每次执行分别生成 `evidence/browser-qa.json`、`evidence/theme-qa/theme-qa.json` 及相关截图；这些文件已被 Git 忽略。本记录为当次实测摘要，脚本是复核入口。
