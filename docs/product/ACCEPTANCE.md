# 验收案例与验证记录

状态：产品文档已完成静态核对；以下应用案例全部未运行，不能作为已实现的证明。当前业务代码仍是原始版本。规则见 [需求方案](REQUIREMENTS.md)，页面预期见 [流程](FLOW.md)。

## 准备与计数口径

开发后按 [README](../../README.md) 安装和启动。Windows 应按仓库要求使用 WSL2 的 Linux 文件系统运行；当前 E 盘目录用于产品交付，无须运行应用。

使用独立测试账号及数据库，默认一条普通任务“整理周报”，时长 2 小时。通过 `wasp db studio` 设置 credits，确保没有遗留进行中请求；新增占用字段或请求表后，测试夹具同步初始化。每例记录初始可用额度 A、占用 H、结果条数 P，以及日志时间区间。

新增调用数 C 按 `mock-ai.started` 的不同 callId 统计；结果增量按同账号 PlanResult 统计。现有模型日志没有 userId，手工验收时避免其他账号同时调用，自动测试由夹具关联请求和账号。以下数值均为本例增量。最终额度在请求全部结束后查询数据库，过程中另检查 A≥0。
