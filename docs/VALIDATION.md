## 打开原型

在仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8765/docs/prototype.html`。也可直接双击 HTML 离线查看。端口被占用时换一个空闲端口；终端按 Ctrl+C 停止。所有原型状态仅在当前页面内存中，刷新即重置，不保存真实账号信息。

原型把 500ms 的本地调用延长到 1800ms，方便观察生成中与重叠请求。右侧“另一标签页”是**同页模拟事件**，没有真正打开第二标签页，也没有实际服务器锁；它不能证明真实接口并发安全。示例任务固定，仅演示额度交互；任务增删改沿用原应用。
