# 验收案例

- 关联：[PRD](PRD.md) · [流程](FLOW.md) · [任务拆解](TASKS.md) · [原型](prototype/index.html)
- 适用：产品原型验收 + 工程实现验收。
- 原则：每条都写清**前置条件、操作、可观察预期、证据**；没跑的明确写“未验证”。

## 1. 证据口径

| 证据 | 产品原型 | 工程实现 |
| --- | --- | --- |
| 页面状态 | 原型截图/横幅文案/余额 | 浏览器或 E2E 截图 |
| 接口 | 无（原型模拟） | HTTP 状态码、响应体 |
| 额度 | 原型余额 | `User.credits` |
| 结果 | 原型日程区 | `PlanResult` 条数 |
| 模型调用 | 原型调用日志 | `mock-ai.started` / `succeeded` / `failed` 日志计数 |

### 2.1 文案检查清单

- [ ] 成功提示同时包含“扣 1”和“剩余 N”。
- [ ] 额度不足提示同时包含“未生成”和“未扣额度”。
- [ ] 模型失败提示同时包含“未扣额度”和重试动作。
- [ ] 无任务/时长错误不出现“扣费”措辞。
- [ ] 0 额度时按钮附近有常驻说明，不只靠 toast。
- [ ] 错误提示没有暴露英文异常或内部堆栈。

## 3. 工程实现验收

以下案例用于真实 Wasp 服务 + PostgreSQL。若产品方向不实现后端，这些是交接给工程的验收标准，不能在产品阶段声称已验证。

| ID | 前置 | 操作 | 可观察预期 | 证据 |
| --- | --- | --- | --- | --- |
| E-AC1 成功 | 账号 3 额度，至少 1 条普通任务 | 调用一次生成 | HTTP 200；返回日程和 `remainingCredits=2`；`User.credits=2`；`PlanResult` 1 条；`mock-ai.started/succeeded` 各 1 | 响应 + DB + 日志 |
| E-AC2 额度不足 | 账号 0 额度，有任务 | 调用一次生成 | HTTP 402；`credits=0`；`PlanResult` 0；无新增 `mock-ai.started`；页面提示未生成/未扣 | 响应 + DB + 日志 |
| E-AC3 模型失败 | 账号 3 额度，含 `[fail]` 任务 | 调用一次生成 | HTTP 502；`credits=3`；`PlanResult` 0；`started` + `failed` 各 1；页面提示未扣、可重试 | 响应 + DB + 日志 |
| E-AC4 并发 1 额度 | 账号 1 额度，普通任务 | 10 个并发请求 | 恰好 1 个 200、9 个 402；`credits=0`；`PlanResult=1`；`started=1`；余额从未为负 | 脚本汇总 + DB + 日志 |
| E-AC5 并发 3 额度 | 账号 3 额度，普通任务 | 10 个并发请求 | 恰好 3 个 200、7 个 402；`credits=0`；`PlanResult=3`；`started=3` | 脚本汇总 + DB + 日志 |
| E-AC6 连续耗尽 | 账号 3 额度，普通任务 | 连续生成 4 次 | 前 3 次 200，第 4 次 402；`credits=0`；`PlanResult=3`；`started=3` | 响应序列 + DB |
| E-AC7 失败退款后重试 | 账号 3 额度，含 `[fail]` 任务 | 失败 → 删除 `[fail]` 任务 → 再生成 | 第一次 502 且额度 3；第二次 200 且额度 2；只扣成功那次 | 响应 + DB |
| E-AC8 无任务/非法时长 | 账号 3 额度 | 无任务生成；或 `hours=0/25` | HTTP 400；额度 3；无 `started`；无 `PlanResult` | 响应 + DB + 日志 |
| E-AC9 加载中重复提交 | 账号 3 额度 | 快速双击/重复调用同一页面 | 同一页面只发 1 个请求、只扣 1 次；按钮禁用；`PlanResult=1` | 截图 + 网络记录 |
| E-AC10 退款失败（可选） | 模拟 DB 退款异常 | 模型失败后触发退款 | 记录 `credit.refund_failed`；返回 500；人工可定位；不静默吞错 | 日志 + 代码审查 |

## 5. 未覆盖与已知限制

- 真实数据库并发：产品方向未实现后端，只验证了原型中的原子预扣模型；工程必须用真实 DB 重跑 E-AC4/E-AC5。
- 退款失败：未模拟数据库异常，列为工程验收的可选项。
- 网络超时/断网：原型未模拟真实网络；文案已定义，验收需工程配合。
- 多标签页重复请求：v1 没有幂等键；同一页面已禁用重复提交，多标签页可能分别计费。
- 成功后刷新：余额持久化，但最近日程不保留；历史记录不在本轮范围。
- 额度不足的恢复：本地项目没有充值，文案引导联系管理员。
