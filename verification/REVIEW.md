## 真实浏览器走查

通过本机浏览器访问 `http://localhost:43100`，使用隔离测试库中的临时测试账号。运行真实 Wasp 0.25 后端、Vite 前端、Prisma 与 PostgreSQL 18.6；没有替代登录、HTTP 传输或模型接口。43100 端口仅绑定主机 localhost，临时代理仅用于访问容器。

| 场景 | 实际结果 |
| --- | --- |
| 注册及初始状态 | 注册成功、自动登录、额度 3；空待办时生成按钮禁用 |
| 添加任务 | 添加“整理笔记”，额度仍为 3 |
| 正常生成 | 生成期间按钮与刷新按钮禁用；生成成功后额度 2、显示日程与成功提示 |
| 模型明确失败 | 添加含 `[fail]` 的任务后生成返回 502；额度仍为 2；提示返还与重试方式，原日程保留 |
| 失败后重试 | 删除失败任务后可正常生成，额度 2→1 |
| 最后一次 | 再成功生成一次，额度 1→0 |
| 无额度再生成 | 返回 402，提示无可用额度；无新增模型调用，原日程保留 |
| 退出与登录 | 退出返回登录页，重新登录后额度仍为 0、任务存在 |
| 刷新与手动刷新额度 | 页面刷新后会话仍有效；手动刷新额度正常，生成按钮未卡在加载状态 |

服务日志有 5 个生成请求：3 次 200、1 次 502、1 次 402；模型 `started` 共 4 次，其中 3 次成功、1 次失败，402 对应 0 次模型调用。最终数据库为额度 0、结果 3 份、普通任务 1 条。
